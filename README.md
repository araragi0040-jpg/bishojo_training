# 結菜と暮らす v002

ストーリーを追うタイプではなく、日々の行動で「桜井 結菜」の体型・性格・好み・話し方が変わっていくスマホ向け育成シミュレーションのv002です。

## v002で変更した点

- キャラクターを「桜井 結菜」に固定し、市販ゲーム寄りのアート/UIへ刷新
- ホーム / 育成 / ステータス / 記録 の4画面構成
- 実際のキャラクターアートをアプリUIへ反映
- 表情画像、体型バリエーション、性格レーダーチャートを追加
- 結菜本人からの「今日やりたいこと」提案を追加
- v001の食事・運動・勉強・遊び・会話・休息ロジックを継承
- LocalStorage自動保存
- 同一ブラウザにv001のデータがある場合は、初回起動時に育成値を自動移行

## GitHub Pagesで公開する

1. このフォルダの中身をGitHubリポジトリへアップロード
2. Settings → Pages
3. Deploy from a branch
4. `main` / `/root` を指定
5. 数分後に公開URLへアクセス

ビルド処理や外部APIは不要です。

## ファイル

- `index.html` : 画面構成
- `style.css` : UI/レスポンシブデザイン
- `app.js` : 育成ロジック、画面遷移、保存、レーダーチャート
- `assets/` : 桜井結菜のキャラクター画像

## 今後の候補

v003では、同一キャラの「立ち絵差分」を体型・服装・表情ごとに分離し、現在のステータスに応じてメイン立ち絵そのものを自動差し替えする構成にすると、育成結果の視覚反映がさらに強くなります。
