# ひより日和 v001

ストーリー主導ではなく、毎日の行動によって「体型・性格・好み・話し方」が変化するスマホ向け育成シミュレーションのプロトタイプです。

## v001で実装済み

- 1日4ターン（朝 / 昼 / 夕 / 夜）
- 食事 / 運動 / 勉強 / 遊び / 会話 / 休息
- 体重 / 体脂肪 / 筋肉 / 体力の変化
- 社交性 / 自信 / 好奇心 / 自立心 / 甘え度 / 知性などの変化
- 行動履歴に応じた好み形成
- 性格・信頼・好みに応じたセリフ変化
- 体型 / 疲労 / 機嫌に応じたキャラクター表示変化
- ランダムな基礎体質（代謝 / 筋肉のつきやすさ等）
- LocalStorage 自動セーブ
- 名前変更 / ゲームリセット
- スマホ優先レスポンシブUI

## 起動方法

`index.html` をブラウザで開くだけで動作します。

ローカルサーバーを使う場合：

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## GitHub Pages

1. このフォルダ内のファイルをGitHubリポジトリ直下にアップロード
2. GitHubの `Settings > Pages`
3. `Deploy from a branch` を選択
4. `main` / `/root` を指定して保存
